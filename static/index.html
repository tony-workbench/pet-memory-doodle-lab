BEHIND THE LITTLE DRAWING

设计与复用

一套简单、可检查的流程。你可以带走提示词，也可以按 README 在自己的电脑上运行。

  1. 1

    输入场景

    描述一个动作，并列出需要保留的物件。直接采用你的文字，不额外调用模型总结。

  2. 2

    固定 v2 约束

    将场景放入第二轮提示词：细黑线、白底、少笔画、指定物件，保持宠物的四足形态。

  3. 3

    图像模型输出

    本地版配置密钥后，显式请求一张 PNG。在线版展示已生成的示例，不调用图像模型。

为什么这样设计

极简，但仍然像宠物
减少毛发与背景细节，保留动物的四足结构，让动作成为画面的主角。
一份模板，反复试验
默认场景对齐选中的 v2 提示词；换场景时沿用同一组画风约束，便于比较结果。
页面和生成逻辑分开
前端负责输入、预览和下载；模板与图像请求各自独立，便于接进自己的产品。
密钥留在服务端
真实生成读取本地进程的环境变量。网页不接收、不保存 API key；在线演示无需密钥。
示例就是示例
已有图片始终明确标注。编辑文字只更新提示词，不播放虚假的生成过程。
